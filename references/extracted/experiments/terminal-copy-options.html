8 variações pro bloco do terminal

O conteúdo atual (whoami + git log fake + focus.md) está em todo portfolio de devops desde 2018. Aqui jeitos diferentes de usar o mesmo container — alguns mantêm a metáfora do bash, outros trocam por algo mais próprio.

1 · process list (top-style) real & verifiable 
$ top -u hiago | head

PID    PROCESS                CPU%   UPTIME
8421   n8n-workflow-engine    12.3   312d
3210   k8s-multi-cluster      8.1    847d
1124   newsletter-pipeline    2.0    96d
0042   thinking-about-infra   inf    13y

Substitui git log por top. Lista o que ele "roda" como processo — sistemas reais que ele opera. Última linha é a piada inteligente: "thinking-about-infra · inf · 13y".

2 · bio paragraph sem fake commands 
$ cat ~/about

hiago felipe
platform engineer · são paulo · 13y

i build infra that doesn't page you at 3am.
deep in n8n, mcp, self-hosted everything.
worked across gov, esports, fintech.

currently writing more than i code.

Larga a teatralidade do bash. Um único cat about + parágrafo curto em primeira pessoa. Menos buzzword, mais voz. A linha "doesn't page you at 3am" tem mais personalidade que qualquer keyword.

3 · code function retorna um objeto 
function hiago() {
  return {
    role:    "platform engineer",
    based:   "são paulo · UTC-3",
    years:   13,
    focus:   ["self-hosting", "ai workflows"],
    open:    ["consulting", "advisory"],
    note:    "infra w/o 3am pages",
  };
}

Troca shell por JS/TS. Sinaliza que ele escreve código, não só roda comandos. Estrutura organizada (role/based/focus) é mais escaneável que git log.

4 · /now style fresh & dated 
$ now

building  n8n self-hosting kit · v2.4 this week
writing   mcp architectures (long-form)
reading   "data-intensive apps" (3rd re-read)
based     são paulo · UTC-3
open for  consulting · advisory

$ updated: may 23 '26

Formato /now à la Sivers. Mostra o que ele está fazendo esta semana, não keywords genéricas. Timestamp no rodapé reforça que é vivo.

5 · n8n workflow own his tool 
$ workflow show --name="my-day"

trigger: 06:30 brt
├─ pull metrics from 6 clusters
├─ run drift checks (terraform plan)
├─ if drift > 0 → page slack
└─ post daily report at 17h

status: running 312d · zero misses

Mostra um workflow n8n real que ele roda — sua rotina como código. Comunica autoridade no tema sem ter que dizer "expert em n8n".

6 · README markdown cat-style sem prompt 
# ~/README.md

# hi, i'm hiago
> platform engineer · são paulo

## currently
- self-hosting everything that fits on a vps
- writing on n8n + mcp architectures
- 13y deep in production infra

## not currently
- writing yaml without a generator

Formato README de github. "## not currently" no final é o tipo de humor seco que senior dev usa. Estrutura familiar pra quem vê dev portfolios.

7 · uptime + man page autoridade + leve humor 
$ uptime
13 years, 4 months in production
zero unplanned downtime

$ man hiago

HIAGO(1)              User Commands

NAME
   hiago — platform engineer, são paulo

SYNOPSIS
   hiago [--consulting] [--advisory]

Combina uptime (estabilidade da carreira) com formato man page (autoridade). O man page é uma piada-meta que dev sênior pega na hora.

8 · htop hybrid visual rico, minimal text 
hiago@portfolio · uptime 13y

cpu  ▇▇▇▇▇▇▇▇▇▇▁▁▁▁ 72%  ai workflows
mem  ▇▇▇▇▇▇▁▁▁▁▁▁▁▁ 43%  self-hosting
i/o  ▇▇▇▇▇▇▇▇▁▁▁▁▁▁ 58%  writing

> based   são paulo · UTC-3
> open forconsulting · advisory

Mais visual — usa barras unicode pra mostrar "alocação" de tempo entre temas. Quebra o monopólio do texto puro. Risco: pode parecer infográfico demais.

Recomendações pessoais:
  • Mais "sênior" → 2 (bio), 7 (man page) ou 6 (readme). Largam o gimmick do bash log.
  • Mais "técnico" → 1 (top) ou 5 (workflow). Comunicam o que ele opera de verdade.
  • Mais "visual" → 8 (htop). Único que quebra texto puro.
  • Mais "vivo / atualizado" → 4 (/now). Mostra que o site é mantido.

Posso também combinar duas (ex.: whoami rápido + now embaixo). Qual ou quais quer ver no index.html?
