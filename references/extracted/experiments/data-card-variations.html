Versão clara, biográfica. Sem deltas — só números cumulativos da carreira. 4 stats grandes em grid 2×2. Cabe melhor entre cards claros (sem virar mancha escura no bento).

Como escolher:
  • V1 · audience → quando "tamanho da audiência" é o ponto. 1 número enorme + lista pra detalhar.
  • V2 · stats grid → quando quer mostrar dimensões variadas (audience + code + content). Mais flexível.
  • V3 · distribution → quando o ângulo é "minha presença é multi-canal e desbalanceada". Mais analítico.
  • V4 · snapshot → versão clara, biográfica. Cabe melhor no bento se já tem cards escuros suficientes (terminal + newsletter).

Combo recomendado pro seu caso: V1 (hero "12.4k") ou V4 (snapshot claro). V2 fica visualmente redundante com o terminal preto vizinho; V3 carrega muita informação pro tamanho do slot.
